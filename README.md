# User table (React + Vite)

Add, edit and delete users. Data is saved in the browser's localStorage.

## Run
    npm install
    npm run dev

Open the local URL shown in the terminal.

## Structure
- src/App.jsx        – holds the user state, search, and add/update/delete logic
- src/UserModal.jsx  – pop-up form used to add and edit a user
- src/UserTable.jsx  – table of users with Edit and Delete buttons
